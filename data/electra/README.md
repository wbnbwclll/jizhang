# 中文 ELECTRA 语义解析测试集

按 [训练方案](../../docs/02-electra-training.md) 第 2、3、5 节组织。数据固定为测试用途，训练、验证和选阈值时应排除这些样本及其改写。

| 文件 | 内容 |
| --- | --- |
| `test.jsonl` | 340 条 UTF-8 JSONL。17 个标签各 20 条，其中手输与模拟 ASR 各 10 条。 |
| `test-expected.jsonl` | 按 `id` 对应的业务预期，包括金额分值、方向、分类、商户、事项和日期检查方式。 |

每个 `groupId` 对应一个场景和两种文本表达，共 170 组。跨度按原文 Unicode 码点的左闭右开区间记录，例如含 emoji 的文本在 Kotlin 中切片前要换算成 UTF-16 索引。控制标签的 `spans` 为空，NER 计算应掩蔽这些样本。对应的 `draft: null` 表示应拦截，`prediction` 指定预期的拦截原因。

所有用例固定参考时间为 `2026-11-22T12:00:00+08:00`，时区为 `Asia/Shanghai`。每周从周一开始。日期按以下三种方式判定。

- `exact` 检查 `occurredAt` 的 Unix 毫秒值。
- `calendar_date` 检查 `dateExpected` 对应的本地日期，并核对 `dateTimeText`，具体时分没有固定预期。
- `keep_editor_default` 检查编辑器初始时间得到保留。空的商户或事项也应保持为空。

可记的单笔样本覆盖中文口语金额、全角数字、分值上下限、折扣实付、日期和件数干扰、退款与还款。控制类覆盖计划、否定、询问、本人账户互转、金额或方向不明确和多笔交易。按训练方案逐条设定场景和预期，使用 `step-3.7-flash` 改写模拟 ASR 文本并核对。这些合成文本可用于语义解析回归。真实录音与 Vosk 的识别效果需要独立验收。
